4. Phạm vi MVP
4a. MVP có trừ Credit thật không? Nếu có thì cần thêm API Admin cộng Credit bằng tay.
	- có trừ thật
	- có cần làm thêm API Admin cộng Credit bằng tay
4b. MVP có làm Creator Revenue và ví Creator không? (Đề xuất: MVP vẫn ghi bản ghi Revenue để không mất dữ liệu, còn ví và rút tiền làm sau)
	- có, nhưng chưa làm nghiệp vụ rút tiền.

4c. Admin dùng chung bảng users, phân biệt bằng cột role, được không? MVP có cần API Admin (ẩn Creative, cấp verified, cộng Credit) không?
	- MVP không cần API Admin (ẩn Creative, cấp verified, cộng Credit)
	- Được Admin dùng chung bảng users, phân biệt bằng cột role
4d. Người mua có cần đăng nhập mới xem được danh sách và chi tiết Creative không, hay xem tự do và chỉ cần đăng nhập khi bấm tạo ảnh?
